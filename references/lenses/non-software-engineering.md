# Lens: Non-Software Engineering

**Focus:** PE license + project scale + domain certifications.

**Evaluate:** PE/EIT status, engineering discipline match, CAD/analysis tools, project scale and complexity, regulatory compliance experience.

**Watch for:** PE license requirements vary by state and discipline. The "Engineer" title is legally protected in some jurisdictions. Field vs. office role distinction.

**Resume tip:** PE/EIT status with state. Project values and scale. Standards and codes worked to. Software tools (AutoCAD, MATLAB, SolidWorks).

**Scoring emphasis:** Credentials are **PASS/FAIL** wherever a PE stamp is legally required; otherwise credentials still outweigh seniority.

Exact weights and the PASS/FAIL rules live in `${CLAUDE_PLUGIN_ROOT}/references/scoring-rubric.md`, which is authoritative.
